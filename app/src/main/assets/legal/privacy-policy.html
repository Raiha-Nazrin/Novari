Privacy Policy

Effective Date: August 16, 2026 · Operated by: Shiburaj RS · Contact: shiburaj525@gmail.com

1. Introduction

Novari is a personal finance and expense-tracking application operated by Shiburaj RS. Novari helps users record, organize, search, and understand personal expenses. It supports manually entered transactions and automatic transaction creation from relevant financial SMS messages.

Your privacy is a core principle of Novari. Version 1.0 is designed to operate completely offline on the user's device. Novari does not operate a backend server and does not transmit transaction data or SMS-derived transaction information to a Novari server.

2. Information Novari Processes

2.1 Manually Entered Transaction Information

When you manually create an expense or transaction, Novari may store the transaction amount, merchant or payee, category, transaction date and time, transaction type, and other information you voluntarily enter where supported.

This information is stored locally on your device.

2.2 Financial SMS Information

Novari may request SMS access to provide automatic transaction-entry functionality. This feature is intended to identify relevant financial transaction messages, such as messages associated with banking or UPI transactions.

Novari is designed to process this information locally on your device. Unrelated personal conversations and ordinary non-financial SMS messages are not intentionally processed for transaction creation.

For a relevant financial SMS, Novari extracts information needed for expense management, such as amount, merchant, category, transaction date and time, and transaction type. The extracted information may be stored locally as a Novari transaction. Novari does not require the original SMS text to be stored as part of the transaction record.

3. How SMS Data Is Used

SMS-derived information is used solely to provide automatic transaction-entry and personal expense-management functionality. Novari does not use SMS information for advertising, marketing, user profiling, selling data, sharing data with advertisers, building a database of personal communications, or providing data to unrelated third-party services.

4. Local Processing and Offline Architecture

Novari Version 1.0 is designed to operate offline. In Version 1.0:

  • Novari does not operate a backend server for user data.
  • Transaction information is stored locally on the user's device.
  • SMS-derived transaction information is processed locally.
  • Novari does not transmit transaction information to a Novari server.
  • Novari does not transmit SMS content to a Novari server.
  • Novari does not use an external SMS-parsing service.
  • Novari does not use an external AI service to process SMS messages.
  • Novari does not currently use analytics services.
  • Novari does not currently use crash-reporting services.

Internet-connected backup or synchronization is not part of the current Version 1.0 functionality.

5. Permissions

SMS Permission

SMS access may be requested to enable automatic identification of financial transactions from relevant SMS messages. Where supported, users can continue using functionality that does not require SMS access if they decline the permission.

Notification Permission

Novari may request notification permission for user-requested reminders, alerts, or other application notifications. Notifications are not used for advertising in Version 1.0.

6. Financial Information

Novari may process information relating to personal spending activity, including transaction amounts, merchants, categories, dates, and transaction types. This information is sensitive because it may reveal aspects of financial activity. Version 1.0 is designed so that this information remains on the user's device and is not transmitted to Novari servers.

Users should protect their device using appropriate device-level security measures such as a screen lock, device encryption, and operating-system security updates.

7. Data Storage

Novari stores supported transaction information locally on the user's device. Stored information may include amount, merchant, category, transaction date and time, transaction type, and user-provided transaction information. Novari does not intentionally store unrelated SMS messages as Novari transaction data.

8. Data Sharing

Novari Version 1.0 does not sell, rent, or share users' transaction information or SMS-derived transaction information with third parties. There are currently no Novari backend services or third-party data-processing services used to process transaction or SMS data. Novari does not use financial information for advertising or targeted marketing.

9. Analytics and Crash Reporting

Novari Version 1.0 does not currently use analytics or crash-reporting services. If such services are introduced in a future version, Novari will review the associated data practices and update this Privacy Policy where required.

10. Backup and Synchronization

Cloud backup and multi-device synchronization are not part of Version 1.0. The current version does not provide Novari-controlled cloud storage for user transaction information.

Future versions may introduce optional backup or synchronization functionality, potentially using Google Drive or another appropriate storage provider. If introduced, the applicable data practices and user controls will be disclosed and this Privacy Policy will be updated accordingly.

11. Data Retention

Because Version 1.0 stores transaction information locally, Novari does not maintain a separate server-side copy of that information. Local data remains on the device until deleted by the user, removed through operating-system or application storage controls, removed when the application is uninstalled, or otherwise affected by device-level data-management actions.

12. Data Deletion

Users can delete transaction information through available deletion functionality within Novari. Users may also remove Novari's locally stored application data or uninstall Novari. Because Version 1.0 does not maintain a Novari backend containing user transaction information, there is no Novari server-side transaction database requiring deletion.

13. Security

Novari is designed around a local-first, offline architecture for Version 1.0. Keeping financial information on the user's device reduces the need to transmit that information to a remote server. However, no software or storage mechanism can be guaranteed to be completely secure. Users are responsible for maintaining reasonable security of their device.

14. Children's Privacy

Novari does not currently impose a specific age restriction in its product design. Novari is a personal finance application intended for users who are able to understand and manage their own financial information. Parents or guardians should exercise appropriate judgment regarding a minor's use of financial applications.

15. Third-Party Services

Novari Version 1.0 does not currently use third-party services to process users' transaction data or SMS-derived financial information. The application may rely on operating-system and platform functionality necessary for basic operation.

16. Changes to This Privacy Policy

This Privacy Policy may be updated when Novari's functionality, data practices, legal requirements, or third-party services change. When material changes are made, the updated effective date will be shown at the beginning of this Privacy Policy.
